02 · การเงินผู้ป่วยนอก / ผู้ป่วยใน

โมดูล “งานการเงิน” (เมนู 20-21) รับผิดชอบตั้งแต่การรวบรวมค่ารักษาที่เกิดขึ้นจากทุกจุดบริการ ตรวจสอบสิทธิ คำนวณส่วนเบิกได้/เบิกไม่ได้ ออกใบเสร็จรับเงิน จนถึงการโอนค่าใช้จ่ายข้ามสิทธิ/ข้ามประเภทผู้ป่วย และปิดรอบส่งบิล ทุกอย่างหมุนรอบตารางกลางเพียงตารางเดียวคือ TB_FINANCES

แนวคิดหลัก — ทุกอย่างคือแถวใน TB_FINANCES

ไม่ว่าจะเป็นยา, Lab, X-Ray, หัตถการ, ค่าห้อง, ค่าอาหาร หรือค่าแพทย์ — เมื่อถูกสั่งจากจุดใดก็ตาม ระบบจะสร้าง 1 แถวใน TB_FINANCES ต่อ 1 รายการ โดยมี

  • ORDER_ID — จับกลุ่มรายการที่สั่งพร้อมกัน (1 ใบสั่ง = 1 OrderId)
  • FINANCE_TYPE — ประเภทค่าใช้จ่าย
  • OPDIPD — 'O' หรือ 'I'
  • Context ผู้ป่วย: OPD ผูก SERVICE_ID / CLINIC_ID / OPD_RIGHT_ID · IPD ผูก ADMIT_ID / AN / ADMIT_RIGHT_ID
  • STATUS — สถานะการดำเนินการ (ดู Status Lifecycle)

งานการเงินจึงไม่ได้ “สร้าง” ค่าใช้จ่ายเป็นหลัก แต่ทำหน้าที่ รวบรวม → คำนวณ → เก็บเงิน → ปิดยอด

คอลัมน์เงินและความหมาย

คอลัมน์ป้ายบนหน้าจอความหมาย
PRICE × QUANTITYราคา × จำนวนราคาต่อหน่วยและจำนวน
AMOUNTรวมเงินยอดเต็มของรายการ
CREDITเบิกได้ (Claim)ส่วนที่สิทธิรับผิดชอบ (ตั้งจากอัตราตามสิทธิ)
CASH_RETURNเบิกได้ส่วนที่ต้นสังกัด/สิทธิจะคืนให้ — ผู้ป่วยสำรองจ่ายแล้วเบิกคืนได้
CASH_NOT_RETURNเบิกไม่ได้ส่วนที่ผู้ป่วยต้องจ่ายเอง
COPAYร่วมจ่ายส่วนร่วมจ่ายตามเงื่อนไขสิทธิ
DISCOUNTส่วนลดส่วนลดตามสูตร (DISCOUNT_ID / DISCOUNT_FORMULA)
PAYMENTชำระยอดที่รับชำระจริงในใบเสร็จนี้
REMINBURSEเรียกเก็บยอดที่ยกไปตั้งเป็นลูกหนี้เพื่อไปเรียกเก็บ
COSTต้นทุนต้นทุนสำหรับงานบัญชี/รายงาน
ROOT_PRICE / ROOT_CLAIM / ROOT_COPAY—ค่าตั้งต้นก่อนถูกปรับ ใช้ย้อนกลับตอนโอนสิทธิ/ยกเลิก
กติกาที่ใช้ในหน้าออกใบเสร็จ

ยอดที่กรอกในช่อง payment ถูกจำกัดไม่เกิน cashReturn + cashNotReturn และเมื่อกรอกยอดบางส่วน ระบบจะไล่หัก cashNotReturn (ส่วนที่ผู้ป่วยจ่ายเอง) ก่อนเสมอ ส่วนที่เหลือจึงไปลง cashReturn

ขั้นที่ 0 — ตั้งค่าจุดเก็บเงิน (ทำก่อนเริ่มงานทุกกะ)

  1. เข้าเมนู งานการเงิน › ตั้งค่าจุดเก็บเงิน

    /finance/finance-dashboard-select — เลือก WorkPlace ที่เป็นจุดรับเงินของตัวเอง ค่านี้จะไปเป็น WorkId ในใบเสร็จและใช้แยกยอดรับเงินรายจุด/รายคน

  2. เข้า Dashboard การเงิน

    /finance/dashboard — สรุปยอดรับเงินของจุดที่เลือก มุมมองมี 3 แบบ (constViewFinanceType): 1 = เฉพาะของฉัน · 2 = ทั้งจุดเก็บเงิน · 3 = ทั้งวัน

  3. (ถ้าใช้ระบบคิว) เรียกคิวรับชำระเงิน

    /finance/call-queue-payment — เรียกคิวผู้ป่วยขึ้นจอ แล้วกระโดดเข้าหน้าสรุปค่ารักษาของผู้ป่วยรายนั้น

Flow ผู้ป่วยนอก (OPD)

  • ค้นหาผู้ป่วยHN / บัตร / สแกน
  • ตรวจสอบสิทธิสิทธิของ Visit
  • สรุปค่ารักษารวมทุกจุดบริการ
  • เพิ่มค่าใช้จ่ายที่ไม่ใช่ยา
  • ออกใบเสร็จรับชำระ
  • พิมพ์/จบใบเสร็จ

2.1 ค้นหาข้อมูลผู้ป่วย

/finance/opd/search-patient · สิทธิ OUTPATIENT_FINANCE_DASHBOARD

  • ค้นด้วย HN / ชื่อ-สกุล / เลขบัตรประชาชน หรืออ่านบัตรผ่านเครื่องอ่านบัตร
  • เมื่อเลือกผู้ป่วยแล้ว ระบบจะ set patient context ไว้ใน state และแถบ subheader จะแสดงชื่อผู้ป่วยตลอด session

2.2 ตรวจสอบสิทธิ

/finance/opd/rights

  1. ดูสิทธิที่ผูกกับ Visit

    อ่านจาก TB_OPD_RIGHTS ของ SERVICE_ID ปัจจุบัน

  2. เทียบกับสิทธิหลักของผู้ป่วย

    TB_PATIENT_RIGHTS — ถ้าไม่ตรงกันต้องแก้ที่ Visit ก่อนออกใบเสร็จ

  3. ตรวจสิทธิออนไลน์ สปสช. (ถ้าเปิดใช้)

    ต้องมี Token ที่ตั้งไว้ในเมนูผู้ดูแลระบบ (ดู โมดูล 04)

ทำไมต้องตรวจสิทธิก่อนเสมอ

อัตรา CREDIT / CASH_RETURN / CASH_NOT_RETURN ของแต่ละรายการถูกคำนวณ ตอนสร้างแถวการเงิน โดยอิงสิทธิ ณ ขณะนั้น ถ้าสิทธิผิดแล้วออกใบเสร็จไปแล้ว ต้องยกเลิกใบเสร็จ + โอนสิทธิ (ดู โอนค่าใช้จ่าย) ซึ่งยุ่งกว่ามาก

2.3 สรุปค่ารักษาพยาบาล

/finance/opd/summary · สิทธิ OUTPATIENT_FINANCE_OPD_EXPENSE_SUMMARY

  • แสดงทุกแถว TB_FINANCES ของ Visit จัดกลุ่มตาม Bill Group (TBM_BILLGROUPS)
  • แต่ละบรรทัดแสดง รวมเงิน / เบิกได้ / เบิกไม่ได้ / ส่วนลด / ค้างชำระ
  • ตรวจว่ารายการที่ยัง P Prepared หรือ A Accept ครบหรือยังก่อนออกใบเสร็จ

2.4 บันทึกค่าใช้จ่ายที่ไม่ใช่ยา

/finance/opd/non-drug · สิทธิ OUTPATIENT_FINANCE_OPD_NON_DRUG_CHARGE

  1. เลือกประเภทค่าใช้จ่าย

    Lab / X-Ray / Service / เวชภัณฑ์ — กำหนดโดย financeType ใน route data

  2. ค้นรหัสค่าใช้จ่าย

    เลือกจาก TBM_EXPENSES ระบบดึงราคา + อัตราตามสิทธิมาให้อัตโนมัติ

  3. ระบุจำนวน + จุดที่ให้บริการ

    FROM_WORK = จุดที่บันทึก

  4. บันทึก

    สร้างแถว TB_FINANCES ใหม่ — จุดนี้เองที่เป็นทางลัดสำหรับสร้างเคสทดสอบ เช่นการสั่ง Lab ธนาคารเลือด (ดู โมดูล 01)

2.5 บันทึกออกใบเสร็จ

/finance/opd/create-bill · สิทธิ OUTPATIENT_FINANCE_OPD_BILLING · API POST /api/Bill/CreateBill

  1. เลือกรายการที่จะออกใบเสร็จ

    ระบบดึงรายการค้างชำระมาให้ ติ๊กเลือกได้รายบรรทัดหรือทั้ง Bill Group

  2. ใส่ส่วนลด (ถ้ามี)

    เลือกสูตรส่วนลด (DiscountId/DiscountFormula) ระบบตรวจว่าส่วนลดไม่เกินยอดคงเหลือ

  3. ระบุวิธีชำระเงิน

    รองรับหลายช่องทางพร้อมกันในใบเสร็จเดียว

    ช่องทางฟิลด์ใน BillInputModel
    เงินสดCash, Change (เงินทอน)
    บัตรเครดิตCreditCard (ประเภท), CreditCardNo, CreditCardMoney, CreditCardBank
    เช็คCheque, ChequeNo, ChequeBank
    QR / พร้อมเพย์Qrcode, QrNo, QrBank
    หักเงินมัดจำDeposit, DepositNo, DepositBank, Deposit2

    ถ้ามีเครื่อง EDC ต่อผ่าน EDC-Connect-Agent (WebSocket edcUrl) ระบบจะรับผลรูดบัตรกลับมาเติมให้อัตโนมัติ

  4. ตรวจเลขที่ใบเสร็จ

    BookNo / RunNo มาจากเมนู กำหนดลำดับเลขที่ (Running Number) ระบบเรียก GET /api/Bill/GetBillRunNoList เพื่อเลือกเล่ม

  5. บันทึก

    ระบบสร้างหัวใบเสร็จ + รายละเอียด แล้วอัปเดต TB_FINANCES ของรายการที่ถูกออกใบเสร็จ (PAYMENT, DISCOUNT, สถานะ) พร้อม BillType = 1 (Cash)

  6. พิมพ์ใบเสร็จ

    พิมพ์ผ่าน Stimulsoft (reportUrl) — ถ้าตั้ง forcePrintPreview = true จะเปิด preview ก่อนเสมอ

BillTypeความหมายใช้ที่ไหน
1 Cashใบเสร็จรับเงินสดบันทึกออกใบเสร็จ (งานการเงิน)
2 Chargedใบแจ้งหนี้ / ตั้งลูกหนี้บันทึกข้อมูลเรียกเก็บ (งานเรียกเก็บ)
3 ReceivePaymentใบรับชำระหนี้บันทึกรับชำระเงินจากผู้จ่าย (สปสช./ต้นสังกัด)
4 Discountใบลดหนี้ปรับลดยอดลูกหนี้

Flow ผู้ป่วยใน (IPD)

ต่างจาก OPD ตรงที่ค่าใช้จ่ายทยอยเกิดตลอดวันที่นอนโรงพยาบาล และมี Batch Job คอยลงค่าอัตโนมัติ

  • Admitรับเข้า Ward
  • รับมัดจำ(ถ้ามี)
  • ค่าใช้จ่ายสะสมBatch + Manual
  • Dischargeจำหน่าย
  • สรุปค่ารักษาทั้ง Admit
  • ออกใบเสร็จ+ ตั้งลูกหนี้

3.3 ประวัติการย้ายเตียง/ย้ายหอผู้ป่วย

3.5 สรุปค่ารักษาและออกใบเสร็จ

/finance/ipd/summary → /finance/ipd/create-bill

  1. ตรวจว่าจำหน่าย (Discharge) แล้ว

    ค่าห้องคืนสุดท้ายและค่ายาต้องลงครบก่อน

  2. สรุปยอดทั้ง Admit

    รวมทุก TB_FINANCES ที่มี ADMIT_ID เดียวกัน

  3. แยกส่วนผู้ป่วยจ่าย / ส่วนตั้งลูกหนี้

    ส่วน cashNotReturn → รับเงินและออกใบเสร็จ · ส่วน cashReturn/Credit → ยกไปงานเรียกเก็บ

  4. หักเงินมัดจำที่รับไว้

    ผ่านฟิลด์ Deposit ในใบเสร็จ

  5. บันทึก + พิมพ์

3.6 Hybrid Invoice

/finance/ipd/hybrid-invoice — กรณีที่ 1 Admit ต้องแยกเรียกเก็บหลายสิทธิ/หลายผู้จ่าย (เช่น สิทธิหลักจ่ายส่วนหนึ่ง + ผู้ป่วยจ่ายส่วนเกิน + ประกันจ่ายอีกส่วน) ระบบให้สร้าง Invoice หลายใบจาก Admit เดียว

เงินมัดจำ (Deposit / Earnest Money)

/finance/opd/deposit-receiving-information · /finance/ipd/deposit-receiving-information

  1. รับเงินมัดจำ

    บันทึกยอด + ออกใบรับเงินมัดจำ เก็บไว้เป็นเครดิตของผู้ป่วย

  2. ดูรายการมัดจำคงเหลือ

    หน้าจอนี้แสดงประวัติรับ/หัก/คืน

  3. หักมัดจำตอนออกใบเสร็จ

    ใส่ยอดในช่อง Deposit ระบบตัดยอดคงเหลือให้

  4. คืนเงินมัดจำส่วนเกิน

    ถ้ายอดค่ารักษาน้อยกว่ามัดจำ

โอนค่าใช้จ่าย (Transfer)

/finance/transfer/... — ใช้แก้เคสที่ “ลงค่าใช้จ่ายไว้ผิดที่/ผิดสิทธิ” โดยไม่ต้องลบข้อมูล

การโอนคำนวณเงินใหม่

ข้อควรระวัง

1. ลำดับที่ห้ามสลับ

ตรวจสิทธิ → บันทึกค่าใช้จ่าย → ออกใบเสร็จ ถ้าออกใบเสร็จก่อนแล้วค่อยรู้ว่าสิทธิผิด ต้องยกเลิกใบเสร็จ + โอนสิทธิ + ออกใหม่ ครบทั้ง 3 ขั้น

2. รายการที่ยังไม่ Accept

รายการที่สถานะยัง P อาจยังไม่ครบยอด ควรรอให้หน่วยบริการรับงานก่อนสรุปยอด

3. IPD ต้องรอ Batch

ค่าห้องของคืนสุดท้ายลงตอน 00:05 และค่ายา IPD ลงตอน 07:00 การสรุปยอดก่อนเวลานั้นจะได้ยอดไม่ครบ

4. Running Number

เลขที่ใบเสร็จมาจากเมนูผู้ดูแลระบบ ถ้าเล่มหมดจะออกใบเสร็จไม่ได้ ต้องเพิ่มเล่มใหม่ก่อน (ดู โมดูล 04)

5. ส่วนลดผูกกับสูตร

หน้าจอตรวจว่า discount ต้องไม่เกิน amount − (credit + cashReturn + cashNotReturn + paid) — ถ้าเกินจะบันทึกไม่ได้

6. ยอดเรียกเก็บไม่ได้จบที่โมดูลนี้

ส่วน REMINBURSE / CREDIT จะไปต่อที่งานเรียกเก็บ ต้องปิดสิทธิ + ปิดบัญชีถึงจะเข้ารอบส่งเบิกได้
